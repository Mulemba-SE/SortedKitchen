# SortedKitchen

Chef booking platform built with React, Node.js, and Prisma.

## 🚀 Features

- **Chef Profiles:** Browse and view chef portfolios.
- **Booking System:** Schedule and manage bookings.
- **Authentication:** Secure login for users and chefs.

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Backend:** Node.js, Express
- **Database:** Prisma (ORM)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```
